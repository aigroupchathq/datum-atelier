## 💎 Creative Philosophy: Anti-Generic Atelier Craftsmanship

DATUM Atelier was deliberately conceived to dismantle generic social media tropes:
- **No algorithmic noise, clickbait, or influencer clutter.**
- **No hyper-saturated neon showroom CGI renders.**
- **Authentic British & European Domestic Realism:** Cotswolds honey-stone cottages (*Chipping Campden*), Victorian terraced bay curbsides (*Clifton, Bristol*), suburban block-paved driveways (*Harpenden*), Yorkshire Dales stone barn farmsteads, and Sunday 07:00 AM snow-foam pre-wash rituals on damp bitumen.
- **Haute Horlogerie Precision:** Stamped titanium chassis plaques with machine-cut serials, genuine screw rivets, barometric altimetry, and valvetrain harmonic acoustic synthesis.
- **Porcelain White & Speed Yellow Aesthetic:** A museum-grade canvas (`#F8F9FA` gallery void, `#FFFFFF` crisp surfaces, deep `#09090B` ink typography, and high-society Racing Yellow `#EAB308` / `#FACC15` accents) engineered for WCAG AAA legibility and immaculate poise.

## 🏛️ Sovereign Feature Architecture

### 1. 🛡️ Sovereign Privacy Enclave
* **Automatic Optical Plate Cloaking:** Built-in computer vision simulation with laser sweep detection to protect registration plates via frosted glass, pixelated matrix, or blackout bar redaction.
* **800m Residential Sanctuary Geofence:** Every logged expedition automatically clips departure and arrival polyline endpoints by 800 meters, ensuring home garaging locations remain encrypted.

### 2. 📜 Cryptographic Vehicle Passport & DVSA Induction
* **Immutable Vehicle Chassis Dossier:** Tracks registered keepers, statutory DVSA MOT test histories, certified specialist workshop invoices, and factory baseline specifications.
* **Mayfair & Goodwood Transfer Certificate:** Cryptographic ownership provenance with exportable JSON dossiers for provenance validation.

### 3. 🏁 High-Precision Feed & Expedition Scrubbing
* **Literary Social Feed:** Expressive entries (*B-Road Expedition, Chassis Specification, DVSA Statutory Pass, Workshop Blueprint, Atelier Service Log, Paddock Convoy*).
* **Synchronized Telemetry Scrub Bar:** Scrub across high-resolution route profiles (Snake Pass A57, Llanberis Pass A4086, Cotswolds Roman Way) inspecting real-time speed, lateral G, RPM, and barometric elevation.
* **Haute Horlogerie Stories Rail:** 9:16 vertical stories with custom telemetry overlays, pause/scrub controls, and keyboard navigation (`←` `→` `Space` `Esc`).

### 4. 🎙️ Web Audio Valvetrain Acoustic Studio
* Multi-oscillator Web Audio engine generating realistic mechanical valvetrain harmonics:
  * Dynamic tachometer scrubbing from 800 to 9,000 RPM.
  * Throttle blip actuation with realistic transient decay.
  * Real-time multi-channel VU spectrum analyzer.
  * Side-by-side acoustic comparison of legendary powertrains (Twin-Turbo Straight-6, Flat-6 Atmospheric, naturally aspirated M42, Supercharged V8).

### 5. 🏔️ Mountain Pass Surface Grip Radar
* Real-time micro-climate and road surface friction telemetry station covering legendary mountain passes (*Snake Pass, Llanberis Pass, Bealach na Bà, Hardknott Pass, Cheddar Gorge, Black Mountain Pass*).
* Tracks friction coefficient ($\mu$), dew point margins, dawn frost probability, and PMR446 convoy radio locking.

### 6. 🌐 Transit Carnet Logistics Enclave

* Alpine pass clearance radar (*Stelvio 2,757m*, *Furka 2,429m*, *Großglockner 2,504m*, *Col de Turini 1,607m*).

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
* [Git](https://git-scm.com/)

### Installation & Launch
```bash
# Clone the repository
git clone https://github.com/vD/datum-atelier.git

# Enter the directory
cd datum-atelier

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to experience the atelier.

### Production Build
```bash
npm run build
```
